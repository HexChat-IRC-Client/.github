# HexChat - IRC Client with Network List and Channel Window

## About HexChat

HexChat is an IRC client. HexChat IRC Client is the window. HexChat Network List is named collections of servers you already use. HexChat Channel Window is a room. HexChat Notify List watches a nick you care about. HexChat Script Hook is optional scripts you add on purpose.

Connect only to networks on HexChat Network List you have a reason to be on. Join HexChat Channel Window rooms you were invited to or that you operate. Keep HexChat Notify List short. Keep HexChat Script Hook few. SASL or nickserv as the network documents. HexChat IRC Client is not a port scan of IRC.

HexChat IRC Client, HexChat Network List, HexChat Channel Window, HexChat Notify List, and HexChat Script Hook exist to talk in rooms you already use.

## Key Features of HexChat

- **IRC client as the window** – HexChat IRC Client is connect, nick, and buffers. HexChat Network List is how you pick a host. HexChat Channel Window is where you talk. HexChat Notify List and HexChat Script Hook hang off that client. SASL belongs here, not in a random paste.
- **Network list as the hosts** – HexChat Network List is named networks and their servers. Connect only those. HexChat IRC Client then signs in. HexChat Channel Window autojoin should be rooms you still use. HexChat Notify List can be per network. HexChat Script Hook should not rewrite the list behind you.
- **Channel window as the room** – HexChat Channel Window is a named channel or a query. HexChat Network List is how you got there. HexChat IRC Client is the wire. HexChat Notify List can highlight a nick in that room. HexChat Script Hook might format text; document that.
- **Notify list as a nick watch** – HexChat Notify List is people you already have a reason to catch. Keep it short. HexChat Channel Window should not be every idle room just to see them. HexChat IRC Client still has to be connected. HexChat Network List still has to be the right network. HexChat Script Hook should not spam on every nick change.
- **Script hook as a short set** – HexChat Script Hook is plugins or scripts you chose. Disable what you do not use. HexChat IRC Client should still start. HexChat Network List should still connect. HexChat Channel Window should still send. HexChat Notify List should still fire.

## Quick Start with HexChat

1. **One network** – Add it to HexChat Network List. Open HexChat IRC Client. Ignore HexChat Script Hook. Join one HexChat Channel Window you already use. Ignore HexChat Notify List until that send works.
2. **Nick watch only if needed** – Add one nick to HexChat Notify List. Stay in the HexChat Channel Window that matters. HexChat Network List unchanged. HexChat IRC Client unchanged. No HexChat Script Hook yet.
3. **Script only for a gap** – Enable one HexChat Script Hook. Test send in HexChat Channel Window. Confirm HexChat Network List still connects. Confirm HexChat IRC Client still starts. Confirm HexChat Notify List. Disable if unused.
4. **Room hygiene** – Part HexChat Channel Window rooms you are not on for the shift. Trim HexChat Notify List. Recheck HexChat Network List passwords. Recheck HexChat IRC Client after an update. Recheck HexChat Script Hook.
5. **Review** – HexChat Network List is a backup-able list. HexChat IRC Client only live networks. HexChat Channel Window auditable. HexChat Notify List short. HexChat Script Hook still few.
